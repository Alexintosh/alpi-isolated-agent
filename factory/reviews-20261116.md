# Factory pilot review history

These reviews originally ran before the factory PR existed. Their findings are
imported into the PR for traceability; they are not retroactive GitHub approvals.
All agents use the same GitHub account. Independent model analysis is distinct
from an independent human/GitHub approval.

## Sol review

Requested `gpt-6.1-sol`, reasoning `high`; elapsed 6m39s. Effective model/thinking
was not confirmed by runtime metadata. Frozen eight-file scope included both
predicates, runner/reporter/tests and ATC configuration. Base was again `81fdfa5`.
102/102 tests passed, but additional synthetic reproductions found five defects.
No actionable predicate/configuration defect was found.

| Finding | Coordinator correction | Regression |
| --- | --- | --- |
| P1: skipped suites disappear from summary counts | Reporter forwards structured skip/todo status independently of totals | Passing test plus skipped/todo suite must fail |
| P1: unref'ed descendants survive; CLI SIGTERM leaves workers | Keep group leader alive through completion; clean owned group before settling; handle CLI cancellation | Unref'ed child and SIGTERM tests verify owned PIDs disappear |
| P1: Node interprets validated paths as globs | Reject glob metacharacters throughout canonical absolute paths before spawning | `work[ab]` cannot execute sibling tests |
| P2: worker output bypasses 64 KiB limit | Count structured stdout/stderr event bytes and send fixed overflow status | 128 KiB output fails without exposing text |
| P2: hard links inflate minimum test count | Reject duplicate device/inode identities | Two hard links cannot satisfy a higher minimum |

Corrections were made by the coordinator and verified with real synthetic child
processes. They have not received another independent model approval. The PR
must retain that distinction; passing regressions do not erase the review.

Earlier coordinator reproductions also repaired empty-file wrapper counts and
duplicate symlink inventories. Runner suite after these changes: 40 tests.
Combined predicate/runner suite: 108 tests. Product portable inventory: 202 tests.

## Ongoing review rule

Every subsequent review starts from the PR URL and exact head SHA. Findings,
validation limits, resolution commits and regression evidence belong on that PR.
Review changes on the new head; an older approval or passing run does not qualify
a later push. Use comments for same-account model reviews, not self-approval.

Native macOS/VM/Keychain acceptance, independent collector authenticity,
Bombadil exploration and selective formal models remain outside this pilot.
