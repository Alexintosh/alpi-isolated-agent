Pending requests

Requests from all environments are grouped by destination and method. Once decisions apply only to the requests currently in that group, never future arrivals. Pending requests expire after 55 seconds.

Files

The workspace stays in the VM. Every transfer creates a new folder: no existing file is overwritten. Review the preview before confirming.

Files and folders up to 1 GiB and 20,000 entries. Symbolic links, hardlinks and special files are not supported. Archives are copied as files, without automatic extraction.

Import from your Mac

Choose a file or folder using the native Mac picker, then review the transfer.

The selection may contain project credentials, such as .env files: copying them makes them readable to the guest. App-managed private data and DSH profiles are excluded.

Export to your Mac

Enter a path in the guest workspace, then choose a destination using the native Mac picker.

The exported folder contains the selected item. Changes are not applied automatically to the original project.
